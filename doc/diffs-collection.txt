*diffs-collection.txt*  File comparisons, repository review, and conflicts
*diffs-collection*

diffs-collection.nvim provides :Diff file comparisons, :Review repository
reviews, and conflict resolution. It requires diffs.nvim for syntax and
intra-line highlighting.

INSTALLATION                                *diffs-collection-installation*

Requires Neovim 0.12+ and Git. Install these repositories:

    https://github.com/barrettruth/diffs.nvim
    https://github.com/barrettruth/diffs-collection.nvim

Load diffs.nvim before diffs-collection.nvim. Set configuration before loading
the plugins. Add this example to init.lua to use split repository reviews: >lua
    vim.g.diffs_review = { layout = 'split' }

    vim.pack.add({
      'https://github.com/barrettruth/diffs.nvim',
      'https://github.com/barrettruth/diffs-collection.nvim',
    }, { load = true })
<
The load = true option loads the plugins immediately, in the listed order.
See |vim.pack.add()| for package management. No setup() call is required.

CONFIGURATION                               *diffs-collection-config*
                                            *diffs-collection-components*

Each component is enabled by default. The tables below contain all default
settings. Define them before |vim.pack.add()|. Configure syntax and intra-line
highlighting separately through |g:diffs| in diffs.nvim.

File comparisons                            *g:diffs_diff*

Default configuration: >lua
    vim.g.diffs_diff = {
      default_layout = 'unified', -- 'unified', 'stacked', or 'split'
      difftastic = false, -- true or { args = {} } to enable Difftastic
    }
<
    default_layout
        Layout for :Diff. Default: 'unified'. See |diffs-collection-commands|
        for layout descriptions.

    difftastic
        Structural highlighting with the external difft executable.
        false disables it. true enables it with no extra arguments.
        A table enables it and accepts an args list, which defaults to {}.
        For example: >lua
            vim.g.diffs_diff = { difftastic = { args = {} } }
<
Set vim.g.diffs_diff = false to disable :Diff and its plugin mappings.

Repository review                           *g:diffs_review*

Default configuration: >lua
    vim.g.diffs_review = {
      layout = 'unified', -- 'unified', 'stacked', or 'split'
    }
<
    layout
        Layout for :Review. Default: 'unified'.

Set vim.g.diffs_review = false to disable :Review and its plugin mappings.

Conflict resolution                         *g:diffs_conflict*

Default configuration: >lua
    vim.g.diffs_conflict = {}
<
The empty table enables conflict handling. There are no additional options.
Set vim.g.diffs_conflict = false to disable automatic detection and mappings.
Configure keys with |vim.keymap.set()| and |diffs-collection-mappings|.

COMMANDS                                    *diffs-collection-commands*

Layouts: unified shows old and new line-number columns. stacked shows one
line-number column. Both display the same diff in one buffer. split displays
the old and new content in separate panes.

:Diff [++layout=unified|stacked|split] [object]              *:Diff*
    Compare the current file with the index or a Git object. The current buffer
    includes unsaved edits. Supported objects include revisions, rev:path, index
    paths, and merge stages :1:%, :2:%, and :3:%.

:Diff files [++layout=unified|stacked] [left] [right]
    Compare two files. An omitted right side uses the current buffer. If both
    paths are omitted, compare the last save with the current buffer. Escape
    spaces in explicit paths with a backslash.

:Review [++layout=unified|stacked|split] [++nountracked] [base]  *:Review*
    Review repository changes. A base-only review includes branch, staged,
    unstaged, and optional untracked changes. A..B compares endpoints directly.
    A...B compares B with the merge base. A B is a direct comparison.

GENERATED VIEWS                              *diffs-collection-views*

CTRL-L refreshes the current generated view from its comparison sources. :edit
also refreshes it. Named files read disk content. Buffer comparisons retain the
source buffer, including unsaved edits.

The collection installs dp/do only when generated comparison metadata permits
put/obtain actions. This includes eligible repository review sections. A patch
buffer or a third-party buffer receives highlighting without these actions.
Existing user buffer-local mappings take precedence.

LUA API                                     *diffs-collection-api*

require('diffs-diff')
    open(object?, opts?)             Open a current-file comparison.
    files(left?, right?, opts?)      Open an arbitrary file comparison.
    refresh()                        Refresh the current generated view.

require('diffs-review')
    open(spec?, opts?)               Open a repository review.
    files(bufnr?)                    Return review file entries.
    current(bufnr?)                  Return the current review entry.
    goto_file(target, bufnr?)        Select a review file.
    next_file() / prev_file()        Select the next or previous file.
    toggle_layout(opts?)             Change the review layout.
    select_file(bufnr?)              Select a file with vim.ui.select().

require('diffs-conflict')
    attach(bufnr?) / detach(bufnr?)
    resolve_ours(bufnr?) / resolve_theirs(bufnr?)
    resolve_both(bufnr?) / resolve_none(bufnr?)
    goto_next(bufnr?) / goto_prev(bufnr?)

Conflict resolution changes the working buffer without writing it to disk.

MAPPINGS AND EVENTS                          *diffs-collection-mappings*

<Plug>(diffs-diff)                   Open a horizontal comparison.
<Plug>(diffs-diff-vertical)           Open a vertical comparison.
<Plug>(diffs-refresh)                Refresh the current generated view.
<Plug>(diffs-diff-open-source)       Open the worktree source at the cursor.
<Plug>(diffs-review-toggle-layout)   Toggle the review layout.
<Plug>(diffs-review-next-file)       Select the next review file.
<Plug>(diffs-review-prev-file)       Select the previous review file.
<Plug>(diffs-review-select-file)     Select a review file.

Conflict mappings use <Plug>(diffs-conflict-{action}). Generated merge mappings
use <Plug>(diffs-merge-{action}). Actions: ours, theirs, both, none, next, prev.

User events: DiffsConflictDetected, DiffsConflictResolved,
DiffsConflictDetached, and DiffsMergeReady. Conflict colors use the
DiffsConflictOurs, DiffsConflictTheirs, DiffsConflictBase, and
DiffsConflictMarker highlight groups.

DEVELOPMENT                                 *diffs-collection-development*

From the collection checkout: >sh
    nix develop -c just dev
<
The launcher loads diffs.nvim before diffs-collection.nvim. The Nix flake pins
the core revision.
